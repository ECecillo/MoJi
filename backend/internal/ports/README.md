# internal/ports/

Interfaces définissant les contrats entre `domain/` et le monde extérieur. Le domaine dépend de ces ports, jamais des adaptateurs concrets.

À ce stade (Lot 0), ce dossier est volontairement vide. Premiers ports attendus au Lot 3 (synchronisation de la progression) : `ProgressStore`, etc.

Voir [`docs/rfc/0003-architecture-hexagonale.md`](../../../docs/rfc/0003-architecture-hexagonale.md).
